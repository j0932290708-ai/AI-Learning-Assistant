手機安裝與使用方式

Android：用 Chrome 開啟網站，點選選單 ⋮ →「加到主畫面」→「安裝」。

iPhone：用 Safari 開啟網站，點選分享 →「加入主畫面」，若有「以網頁 App 開啟」請保持開啟，再按「加入」。

不安裝也能直接使用。解題和圖片辨識需要網路；已收藏的題目保存在目前裝置的瀏覽器中。網站閒置後首次開啟可能需約一分鐘。

⚙ AI 設定

預設由網站提供 Google Gemini。也可使用自己的 Gemini API Key；請勿把金鑰貼在題目裡。

按套用後，解題與辨識會透過 HTTPS 將金鑰交給本站後端，用來向 Google Gemini 驗證，使用你的 API 額度。金鑰只留在目前頁面記憶體與當次伺服器請求，不寫入題庫、瀏覽器儲存或應用程式日誌；重新整理或關閉頁面後清除。

📷 拍照／上傳題目

照片有多題時請填題號，留空則辨識整張。也可以在題目欄輸入「第 174 題」再開始解題。

圖片只在裝置上裁切、壓縮至最長邊 1600 像素。小字請先裁切到單題，確認清楚再辨識。

支援 PNG、JPEG、WebP，最大 5 MB。按「辨識圖片」，或選圖後使用照片開始解題，會將圖片送至本站與 Google Gemini；伺服器不保存圖片；解題後原圖會隨討論保存在此瀏覽器。請只拍題目，辨識後先核對文字、數字與圖形條件。
