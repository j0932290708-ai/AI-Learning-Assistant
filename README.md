# AI 全科智慧學習助手

提供八科文字解題、圖片題目辨識、步驟解說、收藏與可安裝的網頁 App，採用 Express 與 Gemini API。

- [開啟正式 AI 版](https://ai-learning-assistant-pnma.onrender.com/)
- [互動展示版](https://j0932290708-ai.github.io/AI-Learning-Assistant/)：使用固定示範答案，首頁提供正式版入口。
- [部署說明](DEPLOY.md)

## 使用方式

1. 選擇數學、國文、英文、基本電學、電子學、數位邏輯、程式設計或微處理機。
2. 輸入題目，或在圖片區選擇圖片／用手機拍照。
3. 圖片題目請按「辨識圖片」，核對並修改辨識結果，再按「使用這段文字作為題目」。這一步會取代題目欄的文字。
4. 按「開始 AI 解題」，AI 會依題目自動判斷科目與解法。
5. 閱讀步驟、答案和表格，按「收藏」保存題目與最終答案。

圖片支援PNG、JPEG、WebP（不支援動畫 WebP），最大 5 MB、最多 2000 萬像素且單邊不超過 10000 像素；後端在呼叫 AI 前檢查 base64、檔案標頭、大小及尺寸資訊，不在伺服器解壓縮圖片。相機與相簿圖片均在裝置端等比例縮至最長邊 1600 像素、轉成 JPEG，再送出；不在後端重新壓縮。按「辨識圖片」，或選圖後使用照片開始解題，才送至後端及 Google Gemini；本站不把圖片寫入檔案或題庫。請拍清楚完整題目，不清楚的文字會提示重新核對。HEIC 等格式請先轉成 JPEG 或 PNG。

## 黑板版操作更新

- 深綠黑板、粉筆配色，首頁直接輸入或拍攝題目，不需選科目或方法；已安裝的獨立 App 隱藏安裝區。
- 「開啟相機」使用後置相機預覽，按「拍下題目」才擷取成 JPEG（最長邊 2000 像素）。關閉或切到背景會停止相機；未授權或不支援時可改用系統相機／相簿。
- 多題照片可填「只解第幾題？」或輸入「第 174 題」開始。先辨識指定題目、讓使用者核對並套用，再解題。未找到完整題目時要求重拍；純題號沒有圖片時前後端皆阻止直接解題。
- 每次 AI 請求前先檢查伺服器，超過 6 秒顯示可能正在熱身的提示。啟動最多等 90 秒、AI 回應最多等 75 秒，失敗保留題目。首次造訪若連 HTML 都還未載入，前端無法先顯示動畫；這不是消除 Render 冷啟動。
- 題庫提供 JSON 匯出與匯入（檔案最大 1 MB）；匯入嚴格檢查版本與內容，合併、去重且保留原題。超過 20 題則整次拒絕，不截掉原有資料。這次未提供 PDF 匯出。
- 不支援的圖解顯示原因及「查看解題步驟」連結。

## 學習互動更新

- 辨識、解題時顯示骨架動畫與進度訊息，遵循減少動態效果設定；這是完整回應前的載入畫面，未採用串流生成。
- KaTeX 0.18.7 由本站提供，支援美元符號和反斜線括號包住的 LaTeX、分數與根號；先保護程式碼再排版。禁用不受信任的連結／載入指令，限制巨集展開與公式尺寸；無法排版時保留原文。
- 「裁切題目」可拖曳框選或調整百分比，保留原圖以便「還原整張」；所有編輯在裝置端完成，按辨識才上傳。原始檔仍需在 5 MB、2000 萬像素內；輸出最長邊 1600 像素，JPEG 品質 0.88。先裁切單題能保留較清楚的小字。
- 「直接看答案與步驟」及「引導式提示」可切換；引導模式給 1–3 個提示與一個下一步問題，學生可在結果下方填寫嘗試再繼續。模式變更會取消舊請求，提示收藏會標示為引導提示。
- 結果下方的補充欄最多 1000 字，可指出錯誤後重新產生。重試帶入原題、補充內容及最多 4000 字的前次回應重新檢查，不會建立客服工單或傳送給其他人。
- 快取版本 v11 包含公式程式與 20 個 WOFF2 字型，收藏中的公式可離線排版。API 限流維持每來源 30 次／分鐘及全程序 60 次／分鐘；解題與辨識共用額度。

## 安裝到手機

- Android：用 Chrome 開啟正式網址，選單 ⋮ →「加到主畫面」→「安裝」，也可按網站的「安裝 App」。
- iPhone：用 Safari 開啟正式網址，分享 →「加入主畫面」，若有「以網頁 App 開啟」請保持開啟，再按「加入」。
- 不安裝也能直接使用。文字解題與圖片辨識需要網路；已快取的頁面和本機題庫可離線開啟。
- 收藏保存在目前裝置、目前網址的瀏覽器中，不會自動同步到其他手機，也不會從展示版自動搬到正式版。
- 免費主機閒置後首次開啟可能需約一分鐘；AI 暫時忙碌時可稍後重試。

官方安裝說明：[Apple](https://support.apple.com/guide/iphone/iph42ab2f3a7/ios)、[Google Chrome](https://support.google.com/chrome/answer/9658361?hl=zh-Hant&co=GENIE.Platform%3DAndroid)。

## 本機執行

1. 使用 Node.js 20 以上版本，執行 `npm ci`。
2. 依 `.env.example` 設定 `GEMINI_API_KEY`，不要把金鑰放入前端或提交到版本庫。
3. 執行 `npm start`，開啟 `http://127.0.0.1:3000`。

`GEMINI_MODEL` 可指定模型。八科各自有 `prompt.js`、`solver.js` 與 fake AI 測試，統一由 `src/subjects/registry.js` 分派。

主要模型回報暫時無法服務（503）時，會用較輕量的 `gemini-3.5-flash-lite` 備援一次；兩次模型呼叫共用 60 秒上限與取消訊號。可設定 `GEMINI_FALLBACK_MODEL` 更換備援模型，或設為 `none` 停用。若選用 `gemini-3.7-flash` 備援，會套用 low thinking。額度、認證等其他錯誤不會觸發備援。

## API

`POST /api/solve` 接受 `{ "subject": "english", "method": "grammar", "question": "She go to school every day." }`，回傳 `success`、`subject`、實際 `method`、`steps`、`answer`，以及科目需要的 `explanation`、`table` 或 `code`。

`POST /api/recognize` 接受 `{ "mimeType": "image/png", "data": "純 base64 圖片資料", "questionNumber": "174" }`（題號可省略），回傳 `{ "success": true, "text": "辨識文字", "questionNumber": "174", "warnings": [] }`。無法確認指定題號或完整題目時 `text` 為空字串，由前端請使用者重拍。資料格式、檔案標頭及解碼後大小均需通過驗證；辨識與解題共用限流、同時請求數及逾時保護。

回應包含 `requestId`。前端不會執行 AI 回傳的 HTML 或程式碼。

## 驗證與限制

- Service Worker 對核心 HTML、CSS、JS、圖示採 cache-first；已成功快取後，開啟畫面不需等待休眠中的伺服器。API 與健康檢查不快取，解題仍需連線。新版安裝會驗證 HTML 與資源型態，避免把主機啟動頁存成離線首頁。每次更動核心畫面資源，都必須同步調高 `public/service-worker.js` 的快取版本。
- 解題與辨識共用每分鐘每個連線來源 30 次、整個伺服器程序 60 次請求上限；限流在解析 JSON 前執行，超限回傳 429 與 `Retry-After`。不盲信客戶端的 `X-Forwarded-For`；反向代理後可能由多位使用者共用來源額度。最多記錄 5000 個來源並清除過期記錄，同時 AI 請求最多 2 筆。
- 上述限流是單一程序的流量保護，重啟會重設，並非帳單或每日費用上限；多副本部署需改用共用限流儲存。API 金鑰只放伺服器環境變數，Google 專案額度與費用仍需在供應商後台管理。
- 未設定定時 Ping 或第三方喚醒服務。首次造訪仍受 Render 冷啟動影響；免費方案的月度時數及平台重啟限制仍適用。

- `npm test`：八科、HTTP API、圖片驗證、取消與逾時、前端互動及離線快取測試。
- `npm run check:syntax`：主要程式語法檢查。
- 自動化測試使用 fake AI，不代表真實模型準確率；實際圖片辨識另以正式網站驗收。
- AI 的解題、辨識及引用均可能出錯，請核對原題與可靠資料。圖解按鈕為已標示的規則式功能，僅支援可確認的格式。
- 收藏目前保留最終答案，未保存完整步驟與表格。
- 手機尺寸的瀏覽器驗證不等於實體裝置安裝驗收；實體手機是否安裝成功需由裝置確認。


自動模式：省略 subject 或設為 auto（method 為 auto），會在單次 AI 請求中判斷科目並解題；支援 direct／guided 及補充條件。回傳實際科目供畫面、收藏與後續圖解使用。無法歸入八科的內容使用 general。


## 個人 Gemini 金鑰、貼圖與提示詞邊界（2026-09-23）

- 首頁不再要求選科目或方法；AI 在同一筆請求內判斷，結果與收藏顯示實際科目。八科以外使用 general。
- 「AI 設定」可套用自己的 Gemini API Key，留空／清除時使用網站預設。只存在頁面記憶體，重新整理或離開頁面即清除；以同源 HTTPS 請求標頭傳到本站，建立該次專用 Google 客戶端，不更動其他使用者或網站環境金鑰。個人金鑰失敗不退回網站額度。
- 不支援自訂 API URL；金鑰只送指定同源 API，不送健康檢查，不跟隨重新導向。應用程式不記錄 provider 原始錯誤、標頭或金鑰，金鑰不放入模型內容、題庫或備份。
- 題目欄支援原生剪貼簿圖片貼上，沿用 5 MB／解析度、壓縮、裁切、OCR 核對流程。普通文字貼上不受影響。
- 純兩個數字的四則運算以 BigInt 分數精確計算，支援小數、負數、全形與尾端 =?，不使用 eval；混合文字、多步算式、引導或補充条件仍送 AI。
- 自動解題將可信教學規則放在 systemInstruction，題目／補充／先前答案另以 JSON 作為 user 內容。所有模型呼叫加入角色與不公開內部設定的邊界；模型不具備檔案、環境或工具存取權限。
- 提示詞防護不能保證模型永遠遵從，也不把公開原始碼中的提示詞當成秘密。真正的金鑰始終不進模型上下文。回答仍須核對。
